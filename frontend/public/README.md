# Public Static Assets (Web)

Files placed in this `public` folder are served directly at the root URL path when running or exporting the web app with Expo Router.

### Examples:
- A file placed at `public/manifest.json` will be accessible at `/manifest.json`.
- A file placed at `public/sample.pdf` will be accessible at `/sample.pdf`.
- An image placed at `public/branding/logo.png` will be accessible at `/branding/logo.png`.

These files are served directly without being processed through the Metro bundler.
